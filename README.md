## 🌟 專案簡介

本網站方便玩家快速查閱《崩壞：星穹鐵道》歷來限定角色的躍遷（卡池）登場紀錄與復刻間隔。除了以版本數計算登場間隔外，也標示了各角色的特殊取得方式（如「星緣相邀」、「聚靈鑄星」、「長期聯動」）與能力加強紀錄（「礪爍新輝」）。

---

## 🎮 功能與介面說明

* **卡池紀錄矩陣表格**：
  * **當前版本高亮**：系統會自動對照今日日期，以琥珀金底色標示目前正在進行中的卡池版本。
  * **十字座標對齊**：滑鼠移至表格上時，會自動高亮該角色與該版本直欄，方便橫向對照登場歷史。
  * **復刻間隔計數**：表格內的數字代表該角色距離上次登場隔了幾個版本，顏色越紅代表等待時間越長。
  * **雙軸排序與快跳**：可自由切換角色登場順序（最新/最舊）與版本時間軸方向（最新在左/最右），並提供按鈕一鍵平滑滾動至最新或最舊卡池。
  * **躍遷資訊與超期警報 (⚠️)**：游標懸浮於角色卡片時可查看實裝版本、目前等待、歷史最長等待與總 UP 次數；若「目前等待」超越該角色的「歷史最長等待紀錄」，會自動觸發 `⚠️ (超期警報!)` 標記（連續小版本會自動合併為同一次 UP，避免數據誤判）。
* **頂部工具列與篩選**：
  * **條件選單**：點擊頂部選單可依「實裝版本」（1.x ~ 4.x）、「命途」、「屬性」或「取得方法」進行複選過濾。
  * **礪爍新輝按鈕**：點擊可一鍵切換，僅顯示獲得能力加強過的角色。
  * **搜尋與縮放**：支援輸入角色名稱關鍵字搜尋，並可透過縮放滑桿調整表格顯示大小（縮放設定與工具列摺疊狀態會自動記憶）。
  * **一鍵高畫質截圖**：提供「📷 截圖」功能，可自動依據當前篩選結果精準裁切無關空白欄位，並產出高清 PNG 圖檔供新分頁預覽。
* **懸浮氣泡說明**：將滑鼠游標停留在命途圖示、取得機制、加強角標或角色卡片上，會跳出對應說明文字。

## ⚙️ 視覺化資料管理後台

本專案附帶專屬的視覺化後台（`editor.html`），方便進行資料維護與校對：

* **一鍵遠端同步**：點擊「從遠端同步最新資料」按鈕，即可自動抓取最新的角色與卡池排程，並將英文暫譯名更新為正體中文。
* **智慧推斷欄位**：新增版本或角色時，系統會自動推算下一個版本號（例如 `4.5上` → `4.5下`）。
* **週年分區與摺疊**：以 4 月 26 日遊戲週年為基準，自動將版本歸類為「第 1 年」、「第 2 年」等，點擊標題即可展開或摺疊舊版本。
* **格式化匯出**：在網頁上編輯完成後，可點擊按鈕直接複製導出標準的 JavaScript 檔案（匯出的程式碼首行會自動帶入當前的更新日期註解）。
