# 崩壞：星穹鐵道 - 限定躍遷一覽表 (Honkai: Star Rail Limited Warp Tracker)

一個輕量、無依賴且功能完整的純前端《崩壞：星穹鐵道》限定角色卡池追蹤工具。提供歷代限定躍遷時間軸、智慧復刻間隔統計、多維度篩選與一鍵高畫質裁切截圖功能。

---

## ✨ 功能特點

- **完整躍遷時間軸**：收錄所有限定角色 UP 紀錄，並完美支援「星緣相邀」（自選池）、「聚靈鑄星」（兌換商店）與長期聯動角色（如 Archer、Saber）。
- **多維度動態篩選**：
  - **實裝版本**：快速切換 1.x、2.x、3.x、4.x 等大版本實裝角色。
  - **命途與屬性**：支援依據命途與屬性組合過濾。
  - **取得方式與強化**：一鍵篩選限定躍遷、自選池、商店角或具備「礪爍新輝」能力加強的角色。
  - **即時搜尋**：輸入角色名稱關鍵字迅速定位。
- **智慧數據統計與超期警報 (⚠️)**：
  - **連續小版本自動合併**：若角色跨越連續小版本（如 4.1上 + 4.1下）登場，系統自動判定為「同一次 UP 活動」，避免間隔數據失真。
  - **超期警報機制**：當角色的「目前等待版本數」超越其過往的「歷史最長等待紀錄」時，懸浮資訊視窗自動觸發 `⚠️ (超期警報!)` 標記。
- **一鍵高畫質精準截圖**：
  - 整合 `html2canvas` 引擎，動態偵測當前篩選角色的有效卡池範圍，自動裁剪無關空白欄位。
  - 修正傳統 Sticky 凍結視窗錯位與角標定位問題，產出高品質獨立 PNG 預覽圖。
- **極致 UI / UX 體驗**：
  - 支援 UI 介面縮放（Scale Slider）。
  - 智慧深色主題與熱區高亮。
  - 雙軸排序控制（角色登場順序與版本時間軸方向切換）。

---

## 🛠️ 技術棧與資料來源

- **前端技術**：原生 HTML5、CSS3、JavaScript (ES6+)，無須任何建置工具（Vite/Webpack）或框架。
- **第三方套件**：[html2canvas](https://html2canvas.hertzen.com/)（用於網頁表格畫布渲染與截圖）。
- **頭像與圖示資源**：非同步介接 [Mar-7th/StarRailRes](https://github.com/Mar-7th/StarRailRes) 開源 API 庫。

```text

```

## 🚀 快速開始

本專案為 **純靜態網頁**，無須安裝任何依賴套件（Node.js/npm）：

1. 下載或複製本專案至本地端：
   ```bash
   git clone https://github.com/your-username/hsr-warp-tracker.git
   ```
2. 直接雙擊開啟 `index.html`，或透過 Live Server / GitHub Pages 部署上線即可使用。

## 📝 資料維護指南

當遊戲迎來新版本或新角色時，只需修改 `js/` 目錄下的資料檔：

### 1. 新增角色 (`js/characters.js`)
```javascript
// 範例：新增新角色
{ 
  name: "角色名稱", 
  elem: "虛數",       // 物理/火/冰/雷/風/量子/虛數
  path: "記憶",       // 毀滅/巡獵/智識/同諧/虛無/存護/豐饒/記憶/歡愉
  runs: ["4.5上"]     // UP 小版本列表
}
```

### 2. 新增版本 (`js/patches.js`)
```javascript
// 範例：新增小版本時間軸
{ patch: "4.5下", date: "26/09/16" }
```
